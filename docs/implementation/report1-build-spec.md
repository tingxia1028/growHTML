1. **REACHABILITY (blocker) — a `report.list` view + a launch command; report saves SOURCE-LESS (vault-level).** The review proved a source-less note persists (`GET /api/notes` lists it) but NO client surface shows it (every list is source-scoped; `allNotes()` has no browser). FIX (the teachback.panel precedent — command-launched pane, NO rail entry, keeps the rail lean):
   - NEW `report.list` view (`registerView({kind:"report.list", render:(_n,ctx)=><ReportListView ctx={ctx}/>})`) listing `entityClient.allNotes()` filtered to `contentType==="study-report.report"`, each rendered via `getNoteType("study-report.report").render`, newest-first; open a report → the preview/editor or a read view. Shell side-effect import (WorkspaceShell.tsx block, the teachback import precedent).
   - A `study-report.open` command "学习报告" → `navigateShell({type:"pane", kind:"report.list"})` (+ the `commandEntries.ts` NAV_COMMANDS entry + `searchMessages.ts` string — the teachback launch precedent, so it surfaces in global search).
   - The report saves via `onGenerated({anchorId:undefined, sourceId:undefined})` → parkDraft → Save `anchor.add-note` `anchorIds:[]` (source-less; `WorkspaceContext.tsx:1605-1610`). Vault-level is the correct semantics; the `report.list` view is its home.
2. **Period-streak semantics (should-fix).** The assembler period-filters rows BEFORE `summarizeMemoryDigests`, so `streakDays`/`activeDays` become WITHIN-WINDOW. Make this EXPLICIT: the report's `stats.activeDays` = active days IN the period (correct for "本周"); ADDITIONALLY surface the learner's GLOBAL current streak as a separate field `stats.streakDays` sourced from an UNFILTERED `summarizeMemoryDigests(allRows).overall.streakDays` (or `deriveProfileFacts` all-time). Document both in the assembler.
3. **Deterministic-stats re-merge (should-fix) — an EXPLICIT command step.** After `generateStructured` returns `{content}`, the command MUST overwrite the AI's `stats` (and `period`) with the deterministically-assembled values BEFORE `onGenerated`/Save (`{...aiContent, stats: computedStats, period: computedPeriod}`), so a schema-valid-but-wrong AI stat can never leak. The AI only owns prose (summary/highlights/nextSteps). Pin `reviewsDone = attempts (pass+fail)`; document `notesCreated` includes bookmarks + the report itself (acceptable).
4. **Correct the footprint count.** It's **3** register-only aggregation edits: `kitContentSpecs` + `kitPrompts` (`src/kits/index.ts`) + `productKits` (`clientKits.tsx`) — PLUS the report.list view's shell import + the 3 launch one-liners (commandEntries/searchMessages/WorkspaceShell import, delta 1). Still zero core-ENGINE edits (no schema/server-route/entity). Use correct paths (`src/client/memory/commandCapture.ts`, `src/client/data/entityClient.ts`).
